## Original post text

有时候在和同学聊面试、聊 BQ 的时候，我会问他们一个问题：
如果这道题是 hiring manager 这样问的，你觉得他大概想了解什么？
很多时候，对方会回答，我不知道
比如说当他问你
“说一件你和别人意见不一致的经历”，
他往往在看你如何处理分歧、是否能在不同观点中推进事情。
当他问你
“有没有一件你做得不太顺利的项目”，
他通常在看你如何面对复杂高风险的问题、如何复盘、以及是否能承担责任。
我慢慢发现一件事：
理解对方在想什么，是一种能力。
这种能力，往往是在成长过程中，一点一点积累出来的。
我以前更多关注一个人的能力、经历和结果。聪明的人就是一定知道对方在意什么。
可我错了
如果一个人没有从 hiring manager 的角度看过简历、面试过人、参与过团队建设，他对一个岗位在组织里意味着什么的理解，通常比较有限。
这些理解，通常来自经历本身。
来自你曾经需要为判断负责、为团队结果负责、和不同角色长期合作过。
《Influence》里提到过，影响力和对人的理解程度有关。
我在 BQ 课程里做的事情，也是围绕这一点展开的。
我会和大家一起拆解 hiring manager 的问题，讨论他可能在关注什么，以及怎样把自己的经历放在对方更容易理解的语境里表达出来。
很多时候，面试结果不佳，和能力并不完全相关。
更常见的情况，是你不知道hire manager在担忧的点。
